# ☕ Flavored – Coffee & More

A modern and responsive café website built with a clean and visually appealing design for showcasing coffee, food, snacks, and desserts.

## ✨ Features

- Responsive café website
- Interactive menu categories
- Product cards with prices and descriptions
- Quantity and size selection
- Responsive mobile navigation
- GSAP animations
- Contact form
- Modern café-inspired UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GSAP
- Remix Icons
- Google Fonts
- Web3Forms
